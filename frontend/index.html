How It Works Under the Hood

Orchestrated with LangChain LCEL

Rather than a monolithic prompt, BlogCraft AI executes a structured 3-phase chaining pipeline using LangChain Expression Language (LCEL) and Server-Sent Events (SSE).

📥

1. Request Payload

Topic, Tone, Length & Language parameters from user

FastAPI @ /generate/blog/stream
🎯

2. Title Chain

title_prompt | llm | StrOutputParser()

[TITLE] event emitted
📐

3. Outline Chain

outline_prompt | llm | StrOutputParser()

[OUTLINE_DONE] emitted
⚡

4. Streaming Blog

blog_chain.stream() chunk by chunk via SSE

Got Questions?

Frequently Asked Questions

How does the LangChain streaming pipeline work?

BlogCraft AI uses FastAPI's StreamingResponse with an event generator that triggers three sequential LangChain LCEL chains: first creating an attention-grabbing title, then constructing a section-by-section outline, and finally streaming the full blog prose token-by-token using blog_chain.stream().

Can I write blogs in languages other than English?

Yes! Simply specify your target language in the Language field (e.g. Urdu, French, Spanish, German, Hindi, Japanese). The LangChain prompt guides the model to adopt natural cultural phrasing and native idioms in that language.

Where are the generated blogs stored?

Articles are automatically formatted and saved inside your backend's outputs/ directory with a clean slugified filename (e.g., outputs/the_future_of_ai.md). You can also download them immediately via the Download .md button or copy them to your clipboard.

Can I export formatted markdown into CMS platforms like Ghost, WordPress, or Medium?

Yes! The generated output adheres strictly to Github Flavored Markdown (GFM). You can paste it directly into Ghost, Dev.to, Hashnode, Notion, Obsidian, or any Markdown-compatible CMS without losing headings, blockquotes, or formatting.
